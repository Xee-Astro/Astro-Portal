# Contributing

Read BUILDING.md and the licensing review first. Keep changes focused and document validation. Do not submit vendor APKs, decompiled code, captured product pages, personal profiles, logos, keys, or runtime images.

Use synthetic fixtures and safe test profiles. Automated tests must not move mounts, start exposures, guide equipment or update firmware. Changes to layout should preserve landscape orientation and reject overlapping transitions. Keep dependencies attributed and maintain their notices. Contributions must be original or licensed compatibly with the project's MIT license.
