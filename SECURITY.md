# Security

This is experimental software without a guaranteed support or security-update schedule. Do not post credentials, profiles, precise location, vendor signing material or unredacted logs in public issues.

For a non-sensitive bug, open an issue with Windows/app versions and a minimal reproduction. For a suspected security issue, use GitHub's private vulnerability reporting if enabled; otherwise contact the repository owner privately before disclosure. Do not assume private reporting is enabled until GitHub shows that option.

ADB and the emulator are intended for local use. Do not expose their ports externally. Download validation pins dependency checksums and vendor certificate fingerprints, but is not a substitute for reviewing upstream packages and terms.
