# Changelog

## 0.5.1 — 2026-11-13

- Android system font size controls on the dashboard: A−, A+, percentage and Reset.
- 80%–200% range in 10% increments, with immediate Android setting readback and saved startup preference.
- No font changes accepted during another operation; boundary buttons disable at their limits.
- Small patch for existing self-contained 0.5.0 installations, with checksums, cancellation, backup and rollback support.
- Validation: 70 offline checks, dashboard checks, live Android font changes, and Windows PowerShell 5 patch data-preservation/cancellation/reapply checks.

## 0.5.0

Initial experimental Windows launcher/installer with dual-app layouts, official app installation/update checks, location forwarding, persistent Notes, landscape compatibility, and native Windows input.
